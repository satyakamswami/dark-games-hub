# 🎮 Dark Games Hub

A stylish browser-based mini games project built using pure HTML, CSS, and JavaScript.

This project contains two interactive games with a modern dark neon UI:

- 🎯 Number Guessing Game
- 🧠 Memory Sequence Game

---

## 🚀 Features

### 🎯 Number Guessing Game
- Random number generation (1–100)
- Score system based on attempts
- Instant feedback
- Keyboard Enter support

### 🧠 Memory Sequence Game
- Sequence memory challenge
- Progressive difficulty levels
- Score tracking
- Interactive color buttons

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
